📁 house_prices_mid/
Корневая папка проекта. Содержит весь код, данные и результаты решения задачи регрессии цен на недвижимость.

📂 data/
Хранение данных на разных этапах обработки.

Исходные данные без изменений
Например:

test.csv

📂 data/processed/
Данные после:
очистки
feature engineering
кодирования категориальных признаков
Например:
train_processed.csv

Используются для обучения моделей

📂 notebooks/
Jupyter-ноутбуки для исследования и экспериментов.

📄 03_modeling.ipynb

Моделирование
Обучение моделей (например: Linear Regression, CatBoost, LightGBM)
Кросс-валидация

Production-ready код (то, что можно запускать без ноутбуков).

✔️ VS Code открыт через data_ml

1️⃣ Открываем Anaconda Prompt
2️⃣ Создаём окружение
conda create -n data_ml python=3.11 -y
После окончания установки должно появиться сообщение вроде:
done
3️⃣ Активируем окружение
conda activate data_ml
В терминале должно появиться:
(data_ml) C:\Users\UserS2025> ✅ Это значит, что окружение активно.
4️⃣ Устанавливаем нужные библиотеки
conda install -y numpy pandas matplotlib seaborn scikit-learn jupyter notebook
pip install catboost lightgbm
5️⃣ Проверяем установку
python -c "import pandas, numpy, matplotlib, seaborn, catboost, lightgbm; print('OK')"
Если вывод OK — всё готово.
6️⃣ Открываем VS Code через data_ml
code .
В VS Code → Python: Select Interpreter → выбираем:
Python 3.11 ('data_ml': conda)
В Jupyter Kernel → тоже выбираем Python (data_ml)
Теперь всё готово для Kaggle-проекта.

👉 и мы сразу начнём ЭТАП 1:
понимание задачи + первый код
